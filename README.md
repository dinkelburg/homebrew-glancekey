# GlanceKey for Homebrew

[GlanceKey](https://www.glancekey.com) unlocks your Mac and Linux computers, and approves sudo on them, with Face ID on your iPhone.

```sh
brew install --cask dinkelburg/glancekey/glancekey      # the Mac app
brew install dinkelburg/glancekey/glancekey-agent       # the Linux program
```

Setup and docs: https://www.glancekey.com/docs

The cask and formula are generated by GlanceKey's release script, so changes here get overwritten.
